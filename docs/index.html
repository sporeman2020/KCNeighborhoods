Roof Color Selector

Recolor building roofs in Kingdoms and Castles, and save groups of roofs as named regions.

Status. The code compiles against the current game (Unity 2019.4.41), but it has not been run in the game yet. The roof tint may not be visible on game buildings. See known issues.

What it does

Roof swatches

Select a building that has a roof and a row of eight preset colors appears. Click one to recolor that building's roof. The choice is saved with your game.

Regions

Open the Regions window, turn on Paint, and drag a rectangle over the map. Every roof inside is collected. Name the group, pick a color, and save it. Apply it again later, or delete it.

Saved with the game

Roof colors and regions are stored through the game's own save system, so they come back when you reload.

Install

  1. Copy the RoofColorSelector folder into your game's mods location.
  2. Start the game and load a save with buildings that have roofs.
  3. Select a building to see the swatch row. Press Regions in the top-left corner for the region window.

The mod is plain C# source, so there is nothing to compile and no asset bundle. Check KingdomsAndCastles_Data\mods\log.txt for Compilation success followed by Found 1 SceneLoaded entry point(s) to confirm it loaded.

How it works

  • Written in C# source only. It uses the game's own building API and Unity's material and texture calls.
  • No custom shader and no asset bundle, so it doesn't depend on a bundle built for one Unity version.
  • Roofs are found by renderer name: any renderer with "roof" in its name counts.
  • Public names use a kc prefix to avoid clashes with other mods.

Known issues

  • The tint may not show. Game buildings take their look from a shared livery texture, and the recolor sets _Color, which is probably white on those materials.
  • Colors can be overwritten. The game can rewrite building materials when it refreshes them. Saved colors are reapplied only on selection and on load.
  • Regions use the building's base point. A roof has to have its base inside the rectangle, so a rectangle that only clips a roof can miss it.
  • Clicks and typing can leak through. Releasing the mouse after a drag may also select a building. Typing a region name may trigger game hotkeys.

Roadmap

  • Confirm the tint is visible. If not, recolor the roof's part of the livery texture with per-building copies.
  • Reapply saved colors when the game refreshes a building's materials.
  • Test regions end to end in a real save.

Written from scratch. Inspired by the District mod by Slooth, but no code or assets are taken from it.
